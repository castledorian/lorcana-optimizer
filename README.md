# Lorcana Optimizer

**Lorcana Optimizer** est un projet open source dont l'objectif est de développer un assistant intelligent de deck building pour **Disney Lorcana**.

🌐 **Site web :**
https://castledorian.github.io/lorcana-optimizer/

## Objectif

L'objectif de ce projet est de proposer un outil capable d'aider les joueurs à construire, analyser et optimiser leurs decks grâce à une approche basée sur les données, les probabilités et les algorithmes.

Contrairement à un simple constructeur de deck, Lorcana Optimizer cherche à répondre à des questions telles que :

* Quel est le nombre optimal d'exemplaires (1 à 4) pour chaque carte ?
* Quelles cartes améliorent réellement le taux de victoire d'un deck ?
* Comment optimiser la courbe d'encre ?
* Quelles sont les meilleures synergies entre les cartes ?
* Quels changements augmentent statistiquement les performances d'un deck ?
* Comment un deck se comporte-t-il face à la méta actuelle ?

## Fonctionnalités prévues

* 📚 Base de données complète des cartes Lorcana
* 🧩 Deck Builder interactif
* 📊 Analyse détaillée des decks
* 🔍 Analyse des synergies
* 📈 Calcul de la courbe d'encre
* 🎯 Optimisation automatique du nombre de copies
* 📦 Suggestions de remplacements
* 📉 Analyse des probabilités de pioche
* 🏆 Analyse de la méta et des matchups
* 🎲 Simulations de parties (Monte Carlo)
* 🤖 Moteur d'optimisation basé sur des algorithmes et, à terme, sur l'apprentissage automatique

## Philosophie du projet

L'objectif n'est pas simplement d'attribuer une note aux cartes.

Chaque carte est évaluée **dans le contexte du deck**, de sa stratégie, de ses synergies et de la méta, afin d'estimer son impact réel sur les performances.

À terme, Lorcana Optimizer devra être capable de recommander automatiquement les modifications offrant le meilleur gain statistique.
